# Cómo configurar tu Plan Único de Cuentas (PUC)

> **Contenido en preparación:** esta página es una plantilla. No debe utilizarse todavía como procedimiento definitivo ni incorporarse a las respuestas de la IA.

## Descripción

Esta guía explicará cómo revisar y preparar el Plan Único de Cuentas de una empresa demo.

## Requisitos previos

- Tener creada y seleccionada una empresa demo.
- Contar con acceso al módulo de Contabilidad.

## Paso a paso

1. Ingresar a Contabilidad y abrir **Configuración**.
2. Seleccionar la opción **PUC**.
3. Revisar la estructura de cuentas disponible.
4. Realizar la configuración inicial requerida para la demostración.

## Resultado esperado

El Plan Único de Cuentas queda disponible para utilizarlo en los registros contables de la empresa demo.

## Errores frecuentes

Pendiente de validación con el equipo funcional.
