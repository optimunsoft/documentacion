# Cómo hacer tu primer asiento contable

> **Contenido en preparación:** esta página es una plantilla. No debe utilizarse todavía como procedimiento definitivo ni incorporarse a las respuestas de la IA.

## Descripción

Esta guía explicará cómo registrar un primer asiento contable dentro de una empresa demo.

## Requisitos previos

- Tener seleccionada una empresa demo.
- Tener disponible el Plan Único de Cuentas.
- Contar con permisos para registrar movimientos contables.

## Paso a paso

1. Ingresar al módulo de Contabilidad.
2. Abrir la opción de comprobantes o asientos contables.
3. Crear un nuevo registro y completar los datos requeridos.
4. Agregar los movimientos débito y crédito.
5. Revisar y guardar el asiento contable.

## Resultado esperado

El primer asiento contable queda registrado y disponible para su consulta dentro de la empresa demo.

## Errores frecuentes

Pendiente de validación con el equipo funcional.
